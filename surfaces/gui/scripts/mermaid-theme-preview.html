Mermaid 配色预览（独立 HTML · 不改 ChemClaw 源码）

三栏对比同一套样例：① 当前 ChemClaw 近似（default）· ② 你期望的语义配色（源码里带 classDef / subgraph style）· ③ 仅渲染侧 base + themeVariables（无 classDef）能达到的上限。

怎么读这页
  • 栏 2 才是「原料紫 / 工艺橙 / 产品粉…」完整效果；需要模型在 Mermaid 源码里写出 classDef 与 :::类型（或你改 Skill 给出配色参考）。
  • 栏 3 是只改 GUI 全局主题时的观感：饼图会按色板彩色化，流程图节点/默认 subgraph 会柔和一些，但不会按语义自动分色。
  • 看完再决定：只上栏 3 / 再改 Skill / 两者都做 / 都不做。本文件可随意改下面脚本里的 THEME_VARS 后刷新。
