# 宏观分析

---

## When to use

**use**

- 问句涉及某个国家、地区或全球整体的宏观经济状况
- 涉及货币政策、财政政策、利率、通胀、汇率、贸易政策
- 涉及地缘政治冲突对经济或金融市场的影响
- 涉及区域经济体、自贸区、特定经济政策的深度分析

**don't use**

- 问句聚焦个股投资分析
- 问句聚焦A股大盘今日行情、板块涨跌
- 问句要求推荐具体标的或配置方案

---

## 取数原则

ChemClaw **没有**万得或其它商业金融语料工具。禁止调用不存在的金融语料工具名。

按数据类型选择**当前已注册**的工具：

1. **公开宏观/政策事实**：`web_search` + `web_fetch`（央行、统计局、官方公报、权威媒体）。
2. **用户已给出金额的汇率换算**：可用 `lookup_fx_rate`（不得编造即期中间价序列当行情库）。
3. **无可靠来源**：明确 unavailable；禁止猜测精确宏观序列或未公开数据。

Web 只能作公开证据，不得伪装成结构化宏观数据库。

---

## 第一步：确定主题领域

从问句确定主题（可多选，一般 1–2 个，不超过 3 个）：

| 主题领域   | 适用场景              |
| ------ | ----------------- |
| 全球宏观综述 | 把握全球增长、通胀与政策主线    |
| 宏观经济综述 | 中美欧等主要经济体数据与政策影响  |
| 国际关系解读 | 评估地缘事件对市场与行业的影响   |
| 财政政策解读 | 理解财政政策取向及对资产定价的影响 |
| 货币政策简报 | 跟踪利率、央行操作与流动性变化   |
| 区域经济分析 | 分析省市产业结构与区域增长潜力   |

---

## 第二步：取数

用自然语言检索公开来源，例如：

| 问句意图 | 检索方向示例 |
| --- | --- |
| 全球宏观最新动向 | IMF / 主要央行 / 权威宏观综述 |
| 美国经济 / 日本财政 | 官方统计与财政部/央行公报 |
| 地缘与贸易 | 官方声明与权威媒体事实报道 |
| 人民币汇率换算 | `lookup_fx_rate`（仅换算用户已给金额） |

多主题时并行 `web_search`，必要时 `web_fetch` 打开官方页核对数字。页面无数字则标 unavailable，禁止用模型记忆填精确序列。

---

## 第三步：输出

根据取数结果用 markdown 回答。区分事实、公开表态与推断。

输出字数：单一经济体概述 300–500 字，多维或跨地区分析 600–1000 字，除非用户特别要求，不超过 1500 字。

---

## 第四步：输出规范

**强制要求：**

- 只使用已注册工具与可核验网页；禁止编造宏观/金融数字
- 引用政策或机构表态时标明可核验来源
- 取不到的指标写明 unavailable / 当前无可靠结构化来源

**严禁：**

- 调用或暗示使用万得或不存在的商业金融语料工具
- 「以上仅供参考」式冗长免责尾巴（一句「不构成投资建议」即可）
