# 宏观分析

---

## When to use

**use**

- 问句涉及某个国家、地区或全球整体的宏观经济状况
- 涉及货币政策、财政政策、利率、通胀、汇率、贸易政策
- 涉及地缘政治冲突对经济或金融市场的影响
- 涉及区域经济体、自贸区、特定经济政策的深度分析

**don't use**

- 问句聚焦个股投资分析 
- 问句聚焦A股大盘今日行情、板块涨跌
- 问句要求推荐具体标的或配置方案

## 取数工具

**wind_financial_reference_content** ：万得（Wind）的智能语料查询工具，支持用自然语言 query 输入，返回 Wind 基于金融服务经验预加工的高质量参考语料，具有高浓缩、高价值特点。适合快速获取定性阐述或分析型内容。

**调用原则：**

1. 本技能仅使用 wind_financial_reference_content 工具获取金融分析语料
2. 该工具返回的是经过预加工的高质量参考语料，包含高浓缩的信息
3. 如返回为空或无有效信息，可调整查询关键词或重新组织查询语句

## 第一步：确定主题领域

从问句、输入内容中通过理解，确定属于以下哪个 Wind 元内容主题领域（可多选，一般 1-2 个，不超过 3 个）：

| 主题领域   | 适用场景              |
| ------ | ----------------- |
| 全球宏观综述 | 把握全球增长、通胀与政策主线    |
| 宏观经济综述 | 中美欧等主要经济体数据与政策影响  |
| 国际关系解读 | 评估地缘事件对市场与行业的影响   |
| 财政政策解读 | 理解财政政策取向及对资产定价的影响 |
| 货币政策简报 | 跟踪利率、央行操作与流动性变化   |
| 区域经济分析 | 分析省市产业结构与区域增长潜力   |

---

## 第二步：取数

**优先调用 `wind_financial_reference_content`**，查询格式：

- 全球维度的主题直接以主题领域名作 query：`"全球宏观综述"`
- 涉及特定国家/地区时加上地区前缀：`"{地区} {主题领域}"`

**以下为一些示例：**

| 问句、输入内容             | 取数查询 query                |
| ------------------- | ------------------------- |
| 给我讲讲全球宏观最新动向        | `全球宏观综述`                  |
| 美国经济综述              | `美国 宏观经济综述`               |
| 伊朗经济全面解读            | `伊朗 宏观经济综述`               |
| 说说日本财政政策            | `日本 财政政策解读`               |
| 欧洲央行最新利率决议影响        | `欧洲央行 货币政策简报`             |
| 美以与伊朗战争后美国与欧洲关系变化如何 | `美伊 国际关系解读` + `欧美 国际关系解读` |
| 自贸港后海南经济分析          | `海南 区域经济分析`               |
| 中美贸易格局变化            | `中美 国际关系解读` + `中国 宏观经济综述` |
| 人民币汇率近期走势           | `中国 货币政策简报`               |

问句涉及多个地区或维度时，拆分为多次独立查询并行调用，每个主题领域单独查询一次。

如返回为空或无有效信息，可调整查询关键词或重新组织查询语句。

---

## 第三步：输出

根据取数步骤返回的内容，针对问句、输入内容，进行回答。
输出的内容应该以合适的统一的 markdown 形式给出，即使取数步骤返回的内容不是 markdown 格式。
输出字数与问题复杂度匹配：单一经济体概述 300-500 字，多维或跨地区分析 600-1000 字，除非用户特别要求，不超过 1500 字。

---

## 第四步：输出规范

**强制要求：**

- 所有分析内容必须来自 wind_financial_reference_content 工具返回的参考语料
- 引用机构或政策表态时标注"据公开表态"，不注明具体来源机构
- 取不到的指标直接省略，不在正文中说明原因
- 正文结束即为输出结尾，不附加任何说明性文字

**严禁出现：**

- "受数据限制……"、"工具未返回……"
- "以上仅供参考"、"免责声明"、"几点说明"、"注："
- 任何解释工具调用状态的文字
