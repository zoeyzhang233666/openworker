# 股票市场分析

---

## 适用边界

**使用本技能的情形：**

- 问句涉及全球或某市场（A股/港股/美股等）的整体行情或综述
- 涉及市场情绪、投资者信心、风险偏好判断
- 涉及龙虎榜数据解读、主力资金动向、北向资金
- 涉及板块轮动、市场热点主题、近期市场关注焦点

**不使用本技能的情形：**

- 问句聚焦某只具体股票的深度分析
- 问句聚焦宏观政策、国家经济形势
- 问句要求具体买卖建议或选股推荐

---

## 取数原则

ChemClaw **没有**万得或其它商业金融语料工具。禁止调用不存在的金融语料工具名。

按数据类型选择**当前已注册**的工具：

1. **A 股结构化行情（OHLC / 指数成分股）**：优先 `lookup_cn_stock_ohlc` / `lookup_cn_stock_quote`。
2. **国内期货**：`lookup_cn_futures_ohlc` / `lookup_cn_futures_quote`（不要用 Yahoo 查甲醇/液化气）。
3. **龙虎榜 / 两融 / 北向历史**：`lookup_cn_stock_feature`。
4. **全球/美股/港股 OHLC**：`lookup_yahoo_ohlc`（非官方 Yahoo Chart，best-effort）。
5. **公告 / 新闻 / 盘面事件背景**：`web_search` + `web_fetch`（公司公告、交易所、权威媒体）。
6. **无可靠来源**：明确写「当前无可靠结构化来源」或 unavailable；**禁止猜测** PE、北向精确持仓、龙虎榜席位成交额等数字。

Web 内容只能作公开证据，**不得伪装成**结构化行情库或金融数据库。化工现货价格走 `chem-price-daily` / chem-data-hub。CN 结构化失败后禁止用网页探测补同一数字。

### 出图约定

- A 股 short-ref：`from_tool`=`lookup_cn_stock_ohlc`，symbol 如 `600519.SH`
- 国内期货 short-ref：`from_tool`=`lookup_cn_futures_ohlc`，symbol 如 `PG` / `MA`
- 全球标的 short-ref：`from_tool`=`lookup_yahoo_ohlc`（指数示例：`^HSI`、`^GSPC`）
- 禁止手抄 labels/ohlc

---

## 第一步：确定主题领域

从问句确定属于以下哪个主题（可多选，一般 1–2 个，不超过 3 个）：

| 主题领域     | 适用场景              |
| -------- | ----------------- |
| 全球股市联动综述 | 判断跨市场共振、风险传导与配置方向 |
| 全球金融市场综述 | 跨资产把握全球风险偏好与交易主线  |
| 盘前市场综述   | 开盘前把握重要事件、数据与关注点  |
| 盘中市场简评   | 盘中快速理解行情异动与驱动因素   |
| 盘后市场简报   | 收盘后复盘涨跌原因并梳理后市线索  |
| 新股情报     | 关注新股发行、申购与上市表现    |
| 再融资情报    | 关注再融资事件对资金流动的影响   |
| 每日大宗交易解读 | 关注大宗成交、折价溢价与机构动向  |
| 每日龙虎榜解读  | 跟踪短线热点、游资席位与交易行为  |
| 南向沪港通解读  | 关注南向资金流向与港股热点变化   |
| 市场情绪解读   | 用情绪指标判断风险偏好与拐点信号  |

---

## 第二步：取数

按主题映射工具（可并行调用）：

| 主题类型 | 工具路径 |
| --- | --- |
| A 股/国内盘面走势 | `lookup_cn_stock_ohlc`（代表性标的） |
| 国内期货走势 | `lookup_cn_futures_ohlc` |
| 全球/美股/港股指数 | `lookup_yahoo_ohlc` |
| 盘前 / 盘中 / 盘后综述 | 结构化事实 + `web_search` / `web_fetch` 事件 |
| 新股 / 再融资 / 情绪背景 | `web_search` / `web_fetch`；无来源不编「机构情绪指标」 |
| 龙虎榜 / 两融 / 北向历史 | `lookup_cn_stock_feature`；字段空则标 unavailable，不得把网页语气写成库表 |

CN 或 Yahoo 失败且无序列时：OHLC/涨跌幅数字标 unavailable，禁止用网页摘要估出 OHLC。

---

## 第三步：输出

根据取数结果回答。统一用合适的 markdown。区分：**事实**（工具/页面）、**媒体/机构观点**（须有来源）、**自己的推断**。

输出字数与问题复杂度匹配：单一主题解读 300–500 字，多维市场综合分析 600–1000 字，除非用户特别要求，不超过 1500 字。

---

## 第四步：输出规范

**强制要求：**

- 只使用本轮已注册工具返回的数据与可核验网页内容；禁止编造金融数字
- 引用机构或媒体观点时标明可核验来源（标题/媒体/日期或 URL）；没有来源不得写「据机构观点」
- 取不到的精确指标写明 unavailable / 当前无可靠结构化来源，**不要省略假装齐全**
- 正文结束即为输出结尾；可简短列出「数据缺口」列表，不要写免责声明堆砌

**严禁：**

- 调用或暗示使用万得或不存在的商业金融语料工具
- 用 Web 伪装成结构化龙虎榜/北向/成交明细库
- 「以上仅供参考」式冗长免责尾巴（一句「不构成投资建议」即可）
