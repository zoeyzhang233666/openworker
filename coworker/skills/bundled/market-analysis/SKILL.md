# 股票市场分析

---

## 适用边界

**使用本技能的情形：**

- 问句涉及全球或某市场（A股/港股/美股等）的整体行情或综述
- 涉及市场情绪、投资者信心、风险偏好判断
- 涉及龙虎榜数据解读、主力资金动向、北向资金
- 涉及板块轮动、市场热点主题、近期市场关注焦点

**不使用本技能的情形：**

- 问句聚焦某只具体股票的深度分析
- 问句聚焦宏观政策、国家经济形势
- 问句要求具体买卖建议或选股推荐

---

## 取数工具

**wind_financial_reference_content** ：万得（Wind）的智能语料查询工具，支持用自然语言 query 输入，返回 Wind 基于金融服务经验预加工的高质量参考语料，具有高浓缩、高价值特点。适合快速获取定性阐述或分析型内容。

**调用原则：**

1. 本技能仅使用 wind_financial_reference_content 工具获取金融分析语料
2. 该工具返回的是经过预加工的高质量参考语料，包含高浓缩的信息
3. 如返回为空或无有效信息，可调整查询关键词或重新组织查询语句

---

## 第一步：确定主题领域

从问句、输入内容中通过理解，确定属于以下哪个 Wind 元内容主题领域（可多选，一般 1-2 个，不超过 3 个）：

| 主题领域     | 适用场景              |
| -------- | ----------------- |
| 全球股市联动综述 | 判断跨市场共振、风险传导与配置方向 |
| 全球金融市场综述 | 跨资产把握全球风险偏好与交易主线  |
| 盘前市场综述   | 开盘前把握重要事件、数据与关注点  |
| 盘中市场简评   | 盘中快速理解行情异动与驱动因素   |
| 盘后市场简报   | 收盘后复盘涨跌原因并梳理后市线索  |
| 新股情报     | 关注新股发行、申购与上市表现    |
| 再融资情报    | 关注再融资事件对资金流动的影响   |
| 每日大宗交易解读 | 关注大宗成交、折价溢价与机构动向  |
| 每日龙虎榜解读  | 跟踪短线热点、游资席位与交易行为  |
| 南向沪港通解读  | 关注南向资金流向与港股热点变化   |
| 市场情绪解读   | 用情绪指标判断风险偏好与拐点信号  |

---

## 第二步：取数

**优先调用 `wind_financial_reference_content`**，直接以主题领域名作为 query。

**以下为一些示例：**

| 问句、输入内容        | 取数查询 query |
| -------------- | ---------- |
| 最新的全球股市综述      | `全球股市联动综述` |
| 全球大类资产最近表现     | `全球金融市场综述` |
| 分析一下龙虎榜最新数据    | `每日龙虎榜解读`  |
| 整体市场情绪解读       | `市场情绪解读`   |
| 今天有哪些大宗交易值得关注  | `每日大宗交易解读` |
| 最近南向资金流入港股哪些板块 | `南向沪港通解读`  |
| 今日开盘前需要关注什么    | `盘前市场综述`   |
| 收盘后帮我复盘一下今天    | `盘后市场简报`   |
| 今天有什么新股值得关注    | `新股情报`     |
| 近期有哪些公司做了定增或配股 | `再融资情报`    |
| 盘中市场有什么异动      | `盘中市场简评`   |

问句涉及多个维度时，拆分为多次独立查询并行调用，每个主题领域单独作为query查询一次。

如返回为空或无有效信息，可调整查询关键词或重新组织查询语句。

---

## 第三步：输出

根据取数步骤返回的内容，针对问句、输入内容，进行回答。
输出的内容应该以合适的统一的 markdown 形式给出，即使取数步骤返回的内容不是 markdown 格式。
输出字数与问题复杂度匹配：单一主题解读 300-500 字，多维市场综合分析 600-1000 字，除非用户特别要求，不超过 1500 字。

---

## 第四步：输出规范

**强制要求：**

- 所有分析内容必须来自 wind_financial_reference_content 工具返回的参考语料
- 引用机构观点时标注"据机构观点"，不注明具体来源
- 取不到的指标直接省略，不在正文中说明原因
- 正文结束即为输出结尾，不附加任何说明性文字

**严禁出现：**

- "受数据限制……"、"工具未返回……"
- "以上仅供参考"、"免责声明"、"几点说明"、"注："
- 任何解释工具调用状态的文字
