# 化工研究报告、周报、日报、月报工作流

## 执行步骤

1. 明确报告主题、时间范围、读者和交付要求；建立证据清单与未完成事项，按需要检索并加载其他 Skill。
2. 先发现相关结构化工具并采集行情/产业数据，再补充可核实的新闻与供需证据。现货、国内期货、国际原油分开标注；来源缺失不能相互冒充。
3. 搜索顺序是建议，可根据工具可用性和用户要求调整；只有确有独立子任务时才自主决定委派，不强制委派、不限制父任务工具。
4. 分段研究并保存工作进展，避免重复检索。大结果分页/聚合并保留原始数据回读路径。遇数据或权限阻塞，报告具体缺口；已有部分内容须标明未完成。
5. 将完整报告写入工作目录 report.md，包含摘要、证据、分析、风险/反例、来源、时间与数据口径；有序列时复用工具 chart_spec 或短引用。
6. 校验表格、图表、引用、计算与报告范围。桌面交付文件与摘要；渠道使用现有 HTML/PNG 交付适配，不在普通消息里输出原始 ChartSpec/Mermaid JSON。

## 兼容与失败处理

本包为纯指令工作流，无脚本、无额外 Python/Node 依赖、无密钥。依赖运行时工具发现与最新 Skill 加载机制。可用工具以当前注册列表为准；发现/加载不授权，目录访问、外部写入、审批继续由 ChemClaw 权限系统处理。工具失败时保留准确错误与已有证据，不能伪称任务完成。

安装后验证：能够 search_skills 并 load_skill，检索目标工具；没有 MCP 时能准确说明缺口。更新后下一次 load_skill 读取最新有效版本。回退使用技能管理的已有版本恢复或停用，不修改引擎路由。
