# 化工期现对照、基差和套利研究工作流

## 执行步骤

1. 确认品种、交割等级、地区、税费、单位、时点及期货合约。缺少关键口径先 ask_user，不能直接用主力连续替代指定合约。
2. search_tools / load_tools 发现现货 get_price_trend 与 lookup_cn_futures_*。独立采集两组数据；WTI/Brent 国际合约可查 Yahoo，国内期货不用 Yahoo 冒充。
3. 先结构化后公开网页回退，遵守用户禁联网限制。注明每项来源、日期、合约和口径；数据不足分别呈现，不编造可比基差。
4. 可比条件满足时计算现货减期货基差，说明运费、仓储、资金、税差和交割限制。区分理论价差与可执行套利；重要结论列失效条件。
5. 保留原始证据索引、计算步骤和图表，验证图表数据与表格一致。

## 兼容与失败处理

本包为纯指令工作流，无脚本、无额外 Python/Node 依赖、无密钥。依赖运行时工具发现与最新 Skill 加载机制。可用工具以当前注册列表为准；发现/加载不授权，目录访问、外部写入、审批继续由 ChemClaw 权限系统处理。工具失败时保留准确错误与已有证据，不能伪称任务完成。

安装后验证：能够 search_skills 并 load_skill，检索目标工具；没有 MCP 时能准确说明缺口。更新后下一次 load_skill 读取最新有效版本。回退使用技能管理的已有版本恢复或停用，不修改引擎路由。
