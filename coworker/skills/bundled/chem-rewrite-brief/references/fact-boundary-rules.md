# 事实边界规则

## 原则

1. `immutable_facts` 只能来自用户原文或用户明确确认的补充；后续只能保持，不可「优化」。
2. 用户未提供的字段写入 `unknown_fields`，不得用常识填充。
3. 不确定的应用描述不得进入 `immutable_facts`；可记入 `prohibited_inferences` 或待确认列表。
4. CAS、纯度、规格、包装、认证、数值声明必须与原文逐字一致（含单位）。
5. 原文内部冲突时标记冲突并 `ask_user`，不得自行选择。
6. 用户仅要求改写时，禁止主动联网补 CAS/纯度/认证/检测/安全结论/案例/价格/交期/排名。

## 禁止默认新增

- CAS / 纯度 / 规格 / 包装
- 认证与检测报告
- 安全等级与「无风险」结论
- 客户案例与市场排名
- 价格与交期
