# 化工现货查询工作流

## 执行步骤

1. 确认品种、现货口径、地区、单位和时间。甲醇/原油等期现歧义会影响答案时才 ask_user；已有明确口径不重复问。液化气/LPG 可检索液化石油气别名。
2. search_tools 按 get_price_trend 名称或现货描述检索，load_tools 后按真实 schema 调用已配置 chem-data-hub。今天/现价只取所需最新样本，趋势才取时间范围。
3. 结构化数据为空或工具不可用时，用户允许联网则检索官方/可核实公开报价，标注来源和抓取日期。不用期货或 Yahoo 价格冒充现货；不要要求用户贴数据代替已有可用工具。
4. 回答注明品名、地区、日期、单位、含税/交付口径及缺失项。时间序列提供趋势图和可核对数值；大回包分段读取，不重复拉取相同数据。

## 兼容与失败处理

本包为纯指令工作流，无脚本、无额外 Python/Node 依赖、无密钥。依赖运行时工具发现与最新 Skill 加载机制。可用工具以当前注册列表为准；发现/加载不授权，目录访问、外部写入、审批继续由 ChemClaw 权限系统处理。工具失败时保留准确错误与已有证据，不能伪称任务完成。

安装后验证：能够 search_skills 并 load_skill，检索目标工具；没有 MCP 时能准确说明缺口。更新后下一次 load_skill 读取最新有效版本。回退使用技能管理的已有版本恢复或停用，不修改引擎路由。
