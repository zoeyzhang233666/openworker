# 宁德时代个股投资逻辑

## 营收增长强劲但利润承压，技术与海外双轮驱动打开长期空间

### 短期业绩回暖逻辑清晰，成本与订单双改善支撑Q4弹性

- **动力电池出货量持续回升**：2024年8月中国动力电池装车量达38.2GWh，同比+32%，连续3个月环比增长，需求端回暖趋势明确。
- **海外大单密集落地**：8–9月斩获宝马、Stellantis、福特等国际车企超200GWh新订单，推动Q4海外收入占比有望突破45%，直接拉动营收增速与毛利率修复。
- **上游原材料价格企稳**：碳酸锂价格自高位回落约40%，稳定在9–10万元/吨区间，显著缓解材料成本压力。
- **产能利用率快速回升**：国内主力工厂产能利用率从Q2的75%提升至Q3的88%，规模效应带动单位制造成本下降，预计Q4毛利率有望回升至18%以上（Q2为16.2%）。

### 长期增长引擎明确，技术迭代与全球化布局构筑护城河

- **全球市占率稳步提升**：2023年市占率37.1%，2024年预计达38–39%，目标2026年突破40%，持续巩固行业龙头地位。
- **海外产能加速落地**：德国图林根基地2025年满产（40GWh）、匈牙利一期2024Q4投产、墨西哥基地规划落地，海外产能占比将从2023年15%提升至2026年超30%，构建“本地化生产+销售”新模型，有效规避贸易壁垒。
- **钠离子电池实现量产突破**：2024年已装车奇瑞、众泰等车型，成本较锂电低30%，2025年将大规模应用于A00级电动车与储能市场，打开中低端增量空间。
- **CTP4.0与麒麟电池3.0持续迭代**：无模组高集成设计推动单位Wh系统成本年降8–10%，麒麟电池3.0能量密度达255Wh/kg，强化技术领先优势。
- **储能业务成盈利结构升级核心**：毛利率超25%，显著高于动力电池（18%），预计2026年储能收入占比将从15%提升至25%以上，推动公司从“规模驱动”转向“技术+高毛利产品”双轮驱动。

### 当前估值具备安全边际，目标价上行空间明确

- **盈利预测稳健**：2026–2028年归母净利润同比增速分别为30%、21%、16%，EPS分别为20.61元、24.85元、28.92元。
- **动态PE处于历史低位**：2026年预测PE为19倍，当前股价对应2026年18.5倍PE，低于可比公司亿纬锂能（2026年18.77倍PE），估值安全边际充足。
- **目标价对应23.3倍PE**：基于2026年盈利预测，目标价494元，较现价有23.9%–25%上行空间，具备显著弹性。

### 核心投资风险提示

- **下游需求不及预期**：新能源汽车销量或储能市场需求疲软，将直接冲击动力电池与储能出货量。
- **原材料价格剧烈波动**：锂、钴、镍等关键材料价格反弹或供应链中断，可能侵蚀毛利率。
- **海外建厂进度滞后**：匈牙利、印尼、西班牙等工厂建设或爬坡慢于预期，拖累全球化产能布局节奏。
- **地缘政治与贸易壁垒升级**：欧美加征关税、强制本地化采购等政策增加出口成本，影响海外市场份额。
- **技术路线竞争加剧**：固态电池、钠离子电池等新技术突破，或比亚迪、亿纬锂能等对手加速追赶，削弱技术领先优势。
- **行业产能过剩风险**：全行业扩产过快导致供需失衡，引发价格战，压制盈利韧性。
