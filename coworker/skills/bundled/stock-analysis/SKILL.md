# 个股分析

---

## 适用边界

**使用本技能的情形：**
- 明确的单一公司名称或股票代码
- 涉及个股的投资逻辑、基本面、财务、技术分析、资金面、股票速览、公司战略、财务报表分析、同业比较、同行比较、研究机构观点、重大事件、近期动态、股价异动、投资者问答

**不使用本技能的情形：**
- 聚焦大盘指数整体表现 
- 聚焦宏观政策、利率、流动性背景
- 要求从市场主线发现方向、寻找候选标的池 
- 需要盘中实时异动提醒
- 只需要一个数据点（现价/PE/市值等）
- 筛选一批股票

---

## 取数工具

**wind_financial_reference_content** ：万得（Wind）的智能语料查询工具，支持用自然语言 query 输入，返回 Wind 基于金融服务经验预加工的高质量参考语料，具有高浓缩、高价值特点。适合快速获取定性阐述或分析型内容。

**调用原则：**
1. 本技能仅使用 wind_financial_reference_content 工具获取金融分析语料
2. 该工具返回的是经过预加工的高质量参考语料，包含高浓缩的信息
3. 如返回为空或无有效信息，可调整查询关键词或重新组织查询语句

---

## 第一步：确认公司名称或股票代码

从问句、输入内容中提取公司名称或股票代码。

- 提取到明确名称或代码，直接进入取数
- 如果确认不了明确的股票名称或代码，可以返回合适的反问问句要求输入源进行信息补充。

---

## 第二步：确定主题领域

从问句、输入内容中通过你自己的理解，确定主题领域。该主题领域必须属于后续词汇（以顿号分割）的一项或多项：投资逻辑、基本面、财务、技术分析、资金面、股票速览、公司战略、财务报表分析、同业比较、同行比较、研究机构观点、重大事件、近期动态、股价异动、投资者问答。确定方式包括直接命中，或高相似度关联。


## 第三步：取数

**调用 `wind_financial_reference_content`**，查询格式为 `"{公司名} {主题领域}"`。

**以下为一些示例：**

| 问句、输入内容 | 取数查询 query |
|---------|-----------|
| 梳理小米集团的投资逻辑 | `小米集团 投资逻辑` |
| 一页纸给我讲清楚宁德时代 | `宁德时代 公司速览通` |
| 谈谈新易盛公司的基本面 | `新易盛 个股基本面分析` |
| 英伟达最新财报解读 | `英伟达 最新财报解读` |
| 做一下中际旭创的技术分析 | `中际旭创 个股技术分析` |
| 从资金面分析天孚通信 | `天孚通信 个股资金面分析` |
| 阿里巴巴的短中长期的战略是什么 | `阿里巴巴 公司战略索引` |
| 比亚迪与同行有哪些独特竞争力 | `比亚迪 公司同业比较` |
| 特变电工近期机构观点掘金 | `特变电工 机构研究汇总` |
| 特斯拉这只股票最近为什么涨 | `特斯拉 近日异动原因` |
| 机构最近怎么看茅台公司 | `贵州茅台 机构研究汇总` |
| 浦发银行管理层对这些问题怎么回应的 | `浦发银行 投资者问答精粹` |

问句涉及多个维度时，拆分为多次独立查询并行调用，每个品类单独一次。

如返回为空或无有效信息，可调整查询关键词或重新组织查询语句。

---

## 第四步：输出
根据取数步骤返回的内容，针对问句、输入内容，进行回答。
输出的内容应该以合适的统一的markdown形式给出，即使取数步骤返回的内容不是markdown格式。
输出字数应该与取数步骤返回的内容总字数相当。除非问句、输入内容特别要求，否则总字数不应该超过1500字。

## 第五步：输出规范

**强制要求：**
- 所有分析内容必须来自 wind_financial_reference_content 工具返回的参考语料
- 引用机构观点统一标注"据机构观点"，管理层表态标注"据管理层公开表态"
- 取不到的指标直接省略，不在正文中说明原因
- 正文结束即为输出结尾，不附加任何说明性文字

**严禁出现：**
- "受数据限制……"、"工具未返回……"
- "以上仅供参考"、"免责声明"、"几点说明"、"注："
- 任何解释工具调用状态的文字
