# D-206 显式 MCP 请求与慢查询诊断

用户于 2026-09-15 授权修复已复现的问题：热点新闻复合任务因中文相邻的 `mcp` 未识别且命中行情投影，丢失 chem-biz-scope；部分调用触发客户端 30 秒空 TimeoutError。

## 行为

- 使用 ASCII 标识符边界识别 MCP，支持中文紧邻；识别当前注册/配置的 MCP 服务器名称，不硬编码 chem-biz-scope 的路由。
- 桌面显式 MCP 请求保留当前会话已注册工具，场景投影不得裁掉工具；不补造未连接接口，权限与用户禁止联网/工具策略仍生效。
- Channel 显式 MCP 请求仅补入指定服务器的已注册工具（未指定名字时保留已注册 MCP），继续限制 shell、Skill、子智能体与轮数。
- 多事件新闻检索中的“价格波动”不单独视为现货查价；明确查现货、期货、走势图仍走现有市场口径。
- `query_scope`、`count_scope`、`progress_snapshot` 三类已观察到的慢查询使用现有 120 秒慢工具上限；环境变量覆盖仍优先，其余默认 30 秒。
- 客户端等待到期取消未完成 future，返回中文结构化错误（服务器、工具、时限、来源）；不声称数据库有索引问题，不自动重试。服务端/传输自身 TimeoutError 与客户端等待到期分别标识。
- MCP 能力以 schema 和实际返回为准；连通测试只能报告实际测试成功的接口，不把经营范围查询说成任意新闻提取能力。

## 验收边界

离线回归验证原始问题、中文/英文/服务器名、同会话连续轮次、Channel 和策略限制、慢查询完成/取消/传输超时；不修改真实账号配置、不打正式包、不安装、不写远端数据。服务端查询性能仍需其维护方日志核验。
