# ChemClaw 现有能力加固规格

状态：用户批准实施（2026-09-27）。源码基线 993d0d0；上游以 GitHub 固定提交为准。

## 用户确认的行为

- 全面加固现有能力，不新增知识图谱等产品功能。
- 子智能体仅只读研究/代码探索；写文件、命令和外发由主助手按原权限处理。未知性质的 MCP 交回主助手，不能按名称猜测只读。
- 每个主任务最多五个并行子智能体；主/子共享每段 300 个成功决策循环，最后 15 个仅主助手汇总/回读/交付。明确继续才增加下一段；累计用量不清零。
- 用户停止整组停止；重启保留记录并等待继续；结果未知的写入不能自动重放。
- 上游沙箱仅评估，不接入；真实验证先隔离。正式构建、安装、合并 main 和真实账号外发另行确认。

## 实现合同

统一主/子状态与检查点；预算暂停、截断和阻塞不记为成功或失败。前台等待超时返回运行状态，不取消任务。旧写入型任务可读但不能静默恢复执行。并行预算预订及继续操作必须原子、幂等。任务作用域隔离，停止/通知/预算不能串任务。

保留权限、目录和显式禁联网；只读限制是执行约束，不只靠提示词。保留原有配置、历史及审批兼容性。长结果由内部记录分页回读。主/子共用模型能力、压缩设置和恢复状态。

## 验收

超过旧 6/10/32 轮；五路并发不突破共享预算；最后 15 轮不新建研究；明确继续、重复继续、重启、停止、迟到结果与汇合去重；只读工具约束；中文长会话、摘要 400、断流各阶段、约 400 工具动态发现；渠道隔离/图表交付/定时任务/Skill 更新与回退。未执行的真实验收不得计作通过。
