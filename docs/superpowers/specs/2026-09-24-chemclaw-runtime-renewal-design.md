# ChemClaw 通用运行内核整改

日期：2026-09-24。状态：用户已批准并明确要求实现。

## 合同

- 保留 ChemClaw 品牌、中文、化工工具、图表、渠道交付与已有权限审批；业务流程迁入可更新 Skill，不以关键词裁剪或硬拒绝工具，不强制委派。
- 桌面与 Channel 共用引擎。身份、会话所有权、目录、联网限制和审批不因渠道或 Skill 放宽。
- 模型能力按 provider/endpoint/model 配置；未知窗口明确为估计。用户设置不静默重置。新安装压缩比例 80%，目标为有效输入预算 50%，预留输出和安全空间。
- 预算计入固定提示、工具 schema、历史及新工具结果；只有明确爆窗可强制压缩。摘要参数遵循能力配置，最大输出不超过 16k。质量校验、原始历史回读、结构化失败诊断及重复失败防护必须具备。
- 大工具集通过通用发现按需加载完整 schema，所有允许工具可检索；发现不构成执行授权。
- 取消业务 3/4/6 轮限制和报告固定时间强停。50 次主循环检查点、默认 150 次总预算；预算耗尽为可恢复暂停。完成、截断、传输失败、停止和等待审批不得混淆。
- 恢复不得重放已完成副作用；不执行未闭合工具参数。未展示/未执行的缓冲响应允许有限重试，展示过的内容保留并明确续接。
- 计量统一 input/output/cache_read/cache_write，区分当前占用与累计消耗。诊断不记录凭据、聊天正文或工具参数。

## 验收

超过 6 轮正常完成；预算暂停及重启恢复不重复写入；400 工具可发现；中文/大结果/模型切换/无 usage 的预算；压缩有空间且无同状态循环；摘要 400/空/推理-only/截断/劣质摘要；各阶段断流；渠道与桌面权限等价；原有停止/审批/定时任务/图表回归。
