# 基础联网与会话模型选择修复

2026-09-28 用户明确要求：基础联网不依赖 Skill 触发，同一对话主动选择的模型不能被下一次提问重置。本规格属于已批准加固计划的缺陷修复，不改变全局模型偏好或用户禁联网约束。

## 已核实

- ToolDiscovery 的固定工具集合没有 web_search/web_fetch；大工具环境需额外发现与加载，普通查资料因此可能遗漏联网能力。
- 通用图表提示仍禁止现货/大陆行情数据不足时使用网页，与已批准的工作流降级政策冲突。
- App.loadSettings 将全局默认模型写入当前对话的 model；设置刷新/延迟响应能覆盖用户选择，后续 userMessage 会携带错误模型。
- WebSocket 首次无历史绑定模型时 switch_model 返回无提示，调用方因此跳过持久化；重连前未提问的选择可能丢失。

## 目标行为

1. web_search/web_fetch 在已授权工具中默认可见，不要求加载任何 Skill；仅用户明确禁工具/禁搜索/禁联网时按现有策略过滤。
2. MCP 与网页可互补；通用提示只要求来源、日期、市场口径可核对，不在图表规范里硬限数据源。Skill 继续指导专业流程。
3. 全局默认模型只初始化未确定模型的新对话。当前对话选择优先，刷新设置不覆盖；切回/重连读取该对话模型，不污染其他对话或默认设置。
4. 用户选择与服务器 ready 响应竞争时不回退到旧选择；首次空对话的模型绑定也保存。连续提问和重建引擎均保持选择。

## 验收边界

模拟搜索服务验证首次请求可直接搜索/读网页、400 工具仍受预算控制、无需 Skill、禁联网仍有效。GUI 检查迟到设置响应、会话切换与连续发送；后台检查重连和持久化。离线通过不代表真实搜索服务在用户网络下稳定；本任务不启动真实渠道、不替换安装版。
