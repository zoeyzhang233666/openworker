# 对话提示体积与渐进展示

用户已授权修复普通问候约 1 万输入 tokens、正文攒齐才显示。基线 0129c2c；本次只改通用上下文组装、兼容流解析与正文展示，不恢复业务关键词路由，不限制基础联网工具。

1. Skill 全目录改为常驻简短发现说明，search_skills 支持检索及分页浏览，load_skill 每次读取最新有效内容；默认技能指针、禁用提示、目录权限与用户规则保留。
2. 图表详细协议保留为内置只读说明工具，常驻提示保留图表存在、使用条件、日线默认和获取方式。无需 Skill 即可使用图表；原格式与渠道交付不变。
3. 自定义端点兼容流允许正文和思考增量输出；仅疑似文本工具调用片段暂存，完整终态后再恢复工具调用。保留已显示正文，不回放；未闭合或长度截断工具不执行。既有显式关闭结构化流配置仍保留文本工具兼容能力，不再代表把整段正文缓存。
4. GUI 不再用 40 个空格分词作为正文显示门槛，中文短答首段即显示。工具到达后沿用现有工具组归档。

验收：离线假 Provider 捕获真实出站请求，拆分 system、工具说明和动态上下文；与同一固定技能目录的旧版对照。阻塞式模拟流验证首段展示先于终态；覆盖工具文本分片、结构化参数、断流、截断、图表和 Markdown。真实 token/时间改善须新增模型测试授权，旧三次额度已耗尽。
