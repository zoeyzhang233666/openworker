# 运行内核整改验收记录

## 已实现范围

本次按用户批准的 2026-09-24 方案完成源码整改与离线验收，未替换正在运行的安装版。

- 通用执行计划取代业务关键词工具裁剪、强制委派和渠道小轮数上限；权限、显式禁联网、身份隔离仍有效。
- 工具按名称/描述检索、分页浏览、按需加载 schema；加载状态随检查点恢复。化工现货、期现和报告步骤迁入三个纯指令 Skill，沿用技能安装与最新有效版本机制。
- 模型能力按提供商/端点/模型绑定；未知窗口标为估计。可保存 99% 阈值，实际触发线还需扣除输出预留与安全空间。既有用户设置未迁移覆盖。
- 对完整出站消息及工具定义计预算，压缩后检查目标空间；必要时对保留引用和摘要限额。固定提示/当前输入仍过大则明确停止，不循环精简。历史可回读，摘要参数错误记录安全诊断，不按爆窗处理。
- 每 50 个成功主循环保存检查点并继续，默认 150 总预算后暂停；GUI 可继续，渠道可回复“继续”。模型请求、工具执行、恢复次数分别计量。串行/并行工具批次均记录在途状态与结果，恢复时不重放已回答调用；在途结果未知时要求先核对外部状态。
- 缓冲分支未展示内容时有限重试；已展示内容保留后续接。缺少完整响应终态、未闭合工具参数不执行。长度截断最多自动续写两次，仍截断则明确暂停。
- 行情别名/聚合移到 MCP 工具适配层，保留原始结果；通用引擎不再承载该业务转换。HTML/PNG、图表和渠道交付继续复用现有模块。
- 设置页、健康接口、打包元数据提供运行修订号、源码提交与修改状态。打包流程仅修改了代码，本次没有执行正式构建。
